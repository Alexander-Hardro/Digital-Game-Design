<h1>Game Development</h1>

Explore a collection of games developed using the <b>Perlenspiel</b> JavaScript game engine. These projects focus on game mechanics, user interaction, animation, puzzle design, and player feedback while demonstrating core principles of game design such as progression, challenge, accessibility, and replayability.

<h1>Projects</h1>

<b>Balloon Pump</b>

<img width="250" height="250" alt="cover" src="https://github.com/user-attachments/assets/39dd1e3c-0b46-4605-9ba1-0af2e9cd7c90" />


Balloon Pump is an arcade-style reflex game where players repeatedly click a hand pump to inflate a balloon. Every successful pump increases the balloon's size, but also brings it closer to bursting. After each pop, the balloon requires even more pumps before exploding again, creating an endless progression system that steadily increases the game's difficulty. The project showcases animation, state management, sound effects, and escalating gameplay mechanics.

<b>Emoji Math Deluxe</b>

<img width="250" height="250" alt="cover" src="https://github.com/user-attachments/assets/9de8ad8b-fa12-49cd-9038-4ce526a1a2cb" />


Emoji Math Deluxe is an educational puzzle game that challenges players to solve mathematical equations using emojis instead of traditional numbers. By recognizing patterns and determining the value of each emoji, players solve increasingly difficult puzzles that combine arithmetic with logical reasoning. The project emphasizes puzzle design, user input handling, and educational gameplay while presenting math problems in a fun and engaging format.

<b>Robin Hood Archery Challenge</b>

<img width="250" height="250" alt="cover" src="https://github.com/user-attachments/assets/58265a2a-d0bd-495b-89b6-2c59f72511fe" />


Robin Hood Archery Challenge is a turn-based target shooting game where players compete against a computer-controlled opponent in a three-round archery contest. Players must carefully time both their vertical and horizontal aim before releasing each shot, with points awarded based on accuracy. The project demonstrates sprite animation, turn-based game flow, scoring systems, AI-controlled gameplay, and responsive user interaction.
